# P0001.12.2：Surface Capability Completion

**状态**：已完成
**日期**：2026-09-29
**依赖**：P0001.12.1（Surface 架构 + gap audit）

## 目标

补齐 P0001.12.1 gap audit 明确的 **G1–G5** 五项产品能力缺口，使 Surface 能够真正解释系统。

本阶段**只补只读事实暴露**，不新增交易能力，不进入 P0001.12.3（AI Assistant / Action Gateway）。

## 范围（严格 G1–G5）

| 编号 | 缺口 | 本阶段落地 |
| --- | --- | --- |
| G1 | Fill 级证据（因果链缺 fill 一环） | `ExecutionView.recent_fills`（有界）+ `evidence.trace` 增加 `fill` 阶段 |
| G2 | Raw Facts drill-down | `RawFactView` + 只读端点 `GET /api/v1/facts/{kind}/{identity}`（有界、截断标记、UNKNOWN 语义） |
| G3 | Equity / Exposure 时间线 | `product/account_timeline.py`（有界缓冲 + 投影）+ 只读端点 `GET /api/v1/portfolio/timeline` |
| G4 | Prediction provider / Accounting 健康 | `snapshot.health.prediction_provider` / `snapshot.health.accounting` |
| G5 | 完整 Readiness Authority 事实 | `ReadinessView.authority_kind / issued_at / expires_at / recovery_generation / market_generation` |

`schema_version` 由 `"2"` 升级为 `"3"`（新增字段与端点）。

## 边界（不包含）

- 不实现任何交易写能力（`api.write` 仍 `unavailable_by_design`）；
- 不改 MakerPolicy / RiskGate / Accounting / ExecutionEngine / Prediction schema；
- 不新增第二套事实来源（全部从既有 Owner 读取）；
- 不做 P0001.12.3 的 AI Assistant / Action Gateway / Action Manifest；
- 不做 P0001.13 的 rate limit / latency / reconciliation 后端；
- 不做权益/敞口的**业务**重算（只暴露已记录事实）。

## 成功标准

1. G1：能从订单追溯到 fill（fill 出现在 `snapshot` 与 `evidence.trace`）。
2. G2：`GET /api/v1/facts/{kind}/{identity}` 返回有界原始事实；缺失 ⇒ 404；截断显式标记。
3. G3：`GET /api/v1/portfolio/timeline` 返回有界 equity/exposure 序列；UNKNOWN 保持 UNKNOWN。
4. G4：provider 状态与 accounting 健康在 snapshot 中可见（未接线 ⇒ UNKNOWN）。
5. G5：authority kind / TTL / generation 在 readiness 视图中可见。
6. 所有新增字段均遵守 `UNKNOWN ≠ 0 / empty / healthy`。
7. 不新增交易写路径；UI 仍只读。
8. 全量测试不回归。

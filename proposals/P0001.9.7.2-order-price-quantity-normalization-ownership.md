# P0001.9.7.2：Order Price / Quantity Decimal Normalization Ownership

状态：已完成
日期：2026-09-29
依赖：P0001.9.6（Binance USDⓈ-M ExecutionAdapter）、P0001.9.7.1

## 问题（实测发现）

策略提案价以 IEEE-754 float 表达；序列化后可能超出交易所 `tickSize` 精度
（真实 Testnet 实测：`83958.20000000001` 被交易所按 precision 拒绝，
`Precision is over the maximum defined for this asset.`）。

D-048 明确 adapter **不自动 round**（拒绝隐式修正），这是正确的；但"谁负责把 price/quantity
变成 tick/step 精确值"在契约中**未定义**，导致调用方只能各自猜测。

## 决策（ownership）

**执行边界（execution domain）中显式配置的归一化步骤拥有该职责**，并且必须使用 `Decimal`：

1. `execution/normalization.py` 提供 `OrderNormalizer` / `NormalizedOrderParams` / `OrderNormalizationError`：
   - 输入用 `str(value)` 转 `Decimal`（避免二进制噪声）；拒绝 NaN/Inf/非正数；
   - 量化到 `tick_size` / `step_size`，**舍入模式必须显式给出**（`ROUND_UP` / `ROUND_DOWN` / `ROUND_HALF_UP`，
     不设默认值——这是业务选择，不由实现方猜测）；
   - 返回 `price_text` / `quantity_text`（普通十进制字符串，无科学计数法）与 `adjusted`（是否被改动）。
2. `connectors/binance/execution/adapter.py` 提供 `normalizer_from_rules(rules, price_rounding=..., quantity_rounding=...)`：
   tick/step 取自交易所 `exchangeInfo` 事实（不硬编码）；放在连接器层是因为 `execution/` 域不得依赖
   `connectors/` 的交易所类型（layering 契约）。
3. adapter 新增 `normalizer: OrderNormalizer | None`：
   - **`None`（默认）⇒ 行为完全不变**：不隐式 round（D-048 保持）；
   - 注入后 ⇒ **本地规则校验与 REST 请求都使用归一后的值**（校验用 float 视图，请求用 Decimal 精确值）。
4. 归一化会移动价格，因此**是否仍满足业务意图（例如 post-only 仍为被动价）由调用方负责**；本 Proposal 不判断业务。

## 边界

- 不修改 MakerPolicy / sizing / RiskGate 阈值；
- 不改变 D-048 的"adapter 默认不 round"；
- 不引入第三方依赖（仅 stdlib `decimal`）；
- `execution/` 域的 import 白名单新增 stdlib `decimal`（`tests/unit/test_execution_isolation.py` 同步）。

## 验收

- 单测 `tests/unit/test_order_normalization.py`（13 条）：float 噪声价 → tick 精确文本；Decimal 而非 float 算术；
  显式舍入模式生效；数量按 step 归一；未改动时 `adjusted=False`；舍入模式必填；非法舍入模式/非法输入/量化后为 0 拒绝；
  `normalizer_from_rules` 使用交易所事实；adapter 未注入 ⇒ 原样发送；注入 ⇒ 请求携带 tick 精确价且无浮点噪声。
- 真实 Testnet execution smoke（仓库外 harness，一笔 post-only）：
  `83692.64968206566` → 归一化 `83692.6` → **CONFIRMED_ACCEPTED**（exchange order id 28609115773）
  → cancel → **open orders 0 / position 0.0（无 POSITION_REMAINS）** ⇒ **PASS**。

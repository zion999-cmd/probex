→ Readiness
→ ExecutionEngine

→ Binance TESTNET

# 架构

目标：

```text
RuntimeDecisionLoop
        ↓
MakerPolicy
        ↓
RiskGate
        ↓
LiveReadinessAuthority
        ↓
ExecutionEngine
        ↓
PrivateExecutionConnector
        ├── PaperExecutionConnector
        └── BinancePrivateExecutionConnector
                ↓
           Binance TESTNET
                ↓
          Private User Stream
                ↓
       OrderTracker / FillLedger
                ↓
          AccountingCore
                ↓
          Product / UI
```

ExecutionEngine 不再拥有 Binance-specific path。

LiveExecutionOrchestrator 如果继续存在，只允许承担 lifecycle / recovery / readiness composition，不再成为另一条独立订单写路径。


- import Binance adapter implementation
- 直接调用 REST client
- 直接处理 listenKey


# 4. Submit 语义保持

必须保留既有三态：

```text

REJECTED
```

- timeout / ambiguous 5xx → UNKNOWN

- 不用 executedQty 合成 fill
- clientOrderId 保持 idempotency / ownership 语义

# 5. TESTNET Readiness 必须真实生效
